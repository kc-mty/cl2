💡 Core Computer Concept

The Input-Process-Output (IPO) Cycle

Every computer functions using three simple core stages: INPUT, PROCESS, and OUTPUT!

1

INPUT

The computer accepts initial data and commands provided by the user.

📌 Example: Typing letters on a keyboard or clicking with a mouse.
2

PROCESS

The computer analyzes gathered data and executes tasks using the CPU (Central Processing Unit).

📌 Example: Calculating math, sorting lists, or following program code instructions.
3

OUTPUT

The computer displays or delivers the final processed results for the user.

📌 Example: Displaying pictures on a monitor screen or printing paper documents.

Components of a Computer System

A desktop computer consists of the System Unit (internal components) and Peripherals (external devices).

Central Processing Unit (CPU)

Acts as the brain of the computer. Made up of three main parts:

  • Control Unit (CU): Fetches and interprets instructions, directs system operations.
  • Arithmetic & Logic Unit (ALU): Handles math calculations (+, -, ×, ÷) and logic choices (AND, OR, NOT).
  • Cache Memory: Fast memory inside CPU storing temporary copies of frequent data.

Motherboard

The primary circuit board connecting essential components:

  • Sockets for CPU & Power Supply
  • RAM Slots & SSD/Hard Disk Sockets
  • Sockets for Input/Output Peripherals

Main Memory (Primary Storage)

RAM (Random Access Memory)

Volatile: Information lost when power turns off. Stores data temporarily for fast processing.

ROM (Read-Only Memory)

Non-volatile: Retains stored info even without power. Stores startup firmware.
