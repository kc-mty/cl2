Computer Architecture Handbook

The IPOS Information Processing Model

Every computer system, from smartphones and laptops to supercomputers, operates on the fundamental IPOS Cycle (Input, Processing, Output, Storage). Understanding how data transforms from raw user input into processed information is key to computer science.

1. Input Hardware

Entry & Control Devices
Direction: IN

Input devices act as the bridge between human physical actions and digital computational environments. They convert mechanical movement, light, soundwaves, or touch pressure into binary signals.

Key Input Hardware Devices

Keyboard Text and command entry
Mouse & Trackpad 2D spatial pointing
Microphone Audio wave capturing
Webcam & Scanner Visual image digitized
Key Technical Characteristic:

Input devices never modify or display results; they strictly transmit data unidirectionally into system memory.

2. Processing Hardware

Computation Engine
Direction: EXECUTE

Processing hardware serves as the computational powerhouse. It fetches code from memory, decodes instructions, and executes arithmetic calculations and logic routines.

Key Processing Hardware Components

CPU (Central Processor) Primary computer 'brain'
GPU (Graphics Card) Parallel 3D rendering
RAM (Primary Memory) Ultra-fast working RAM
Motherboard Main circuit backbone
Key Technical Characteristic:

CPU performance is measured in Gigahertz (GHz, billions of clock cycles per second) and instruction throughput.

3. Output Hardware

Presentation & Media
Direction: OUT

Output hardware takes processed digital binary information from memory and translates it into sensory formats that human beings can see, hear, or feel.

Key Output Hardware Devices

Monitor / Display Pixel visual display
Printer & Plotter Hard copy paper prints
Speakers Acoustic audio wave output
Headphones Personal audio sound
Key Technical Characteristic:

Output devices are non-interactive receivers of system data; they deliver information out without modifying internal files.

4. Storage Hardware

Secondary Storage
Direction: SAVE / READ

Storage devices hold persistent data non-volatilesly. Unlike RAM memory, secondary storage safely retains files, games, operating systems, and programs even when power is turned off.

Key Secondary Storage Devices

SSD (Solid State Drive) High-speed flash memory
HDD (Hard Disk Drive) Magnetic spinning disk
USB Flash Drive Portable flash drive
SD / MicroSD Card Camera & phone memory
Key Technical Characteristic:

Non-volatile memory retains data with zero power supply. Measured in Gigabytes (GB) and Terabytes (TB).

Special Case: Hybrid Input/Output (I/O) Hardware

Some modern devices perform BOTH input and output functions simultaneously.

Advanced Concepts
Touchscreen Display

Input: Touch sensors detect finger taps and gestures.
Output: Screen displays pixels, graphics, and video.

VR Headset (Virtual Reality)

Input: Head tracking motion sensors, gyroscopes & microphones.
Output: 3D visual displays and spatial audio speakers.

Headset with Microphone

Input: Built-in microphone captures your voice audio.
Output: Headphone speakers play game and voice chat sound.
